# Лексика для iPhone

Нативная оболочка для читалки «Лексика»: озвучка всеми голосами iPhone (включая Premium / Enhanced),
перевод Apple на устройстве с запасным вариантом через Google, данные в файле `leksika.json` (видно в «Файлах»).

Сборка идёт автоматически в GitHub Actions при каждом push в `main`: вкладка **Actions** → последний запуск →
**Artifacts** → `Leksika-ipa`. Устанавливается через Sideloadly.
